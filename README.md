# OnnTube4K Native

A native Kotlin Android TV application for Onn 4K Plus. This project contains no HTML or WebView UI.

## Current build

Version 0.1.0 establishes the native Android TV home screen and Media3 direct-stream player test. YouTube search, YouTube stream extraction, ad-free playback handling, SponsorBlock, and selectable YouTube resolutions are not implemented yet.

## Build

GitHub Actions builds a debug APK on pushes to `main`. Open Actions and download the `OnnTube4K-Native-debug` artifact when the build succeeds.
